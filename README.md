# Getting Started
`netget` listens on **ports 80 and 443** and routes every incoming request.

```bash
git clone https://github.com/neurons-me/netget.git
cd netget
```

## Choose

🔷 [Typescript](https://neurons-me.github.io/netget/Typescript/)

```bash
cd Typescript
npm install
npm run build
```
